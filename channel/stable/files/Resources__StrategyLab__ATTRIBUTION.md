# Strategy Lab asset sources

Strategy Lab does not vendor assets from Kallly's TDS Mapper repository.

Tower portraits and optional Top Down reference images are fetched on demand from the Tower Defense Simulator Wiki through its MediaWiki API and cached locally for private Strategy Lab use. The editor remains functional without those cached assets.

Tower Defense Simulator and its game artwork are owned by their respective rights holders. Wiki/community media may carry separate attribution/license requirements; this private Lab keeps the source boundary explicit so an upstream/public release can review and package assets appropriately.
