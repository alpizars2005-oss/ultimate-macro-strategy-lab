# Strategy Lab asset sources

Strategy Lab does not vendor assets from Kallly's TDS Mapper repository.

Tower portraits, optional Top Down map references, and optional reward/drop reference icons are fetched on demand from the Tower Defense Simulator Wiki through its MediaWiki API and cached locally for private Strategy Lab use. The Macro Editor and reward tracker remain functional when those cached visual assets are unavailable; image retrieval is cosmetic and never part of gameplay timing.

The neutral footprint-guide PNG is a Strategy Lab UI asset generated specifically for the editor and is not copied from Tower Defense Simulator.

Tower Defense Simulator and its game artwork are owned by their respective rights holders. Wiki/community media may carry separate attribution/license requirements; this private Lab keeps the source boundary explicit so an upstream/public release can review and package assets appropriately.
